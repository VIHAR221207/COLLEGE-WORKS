# Analysis of Algorithms (AiDS) - Lab Experiments

C programs for the Analysis of Algorithms practicals (SE-A, Semester 3, Course Code 2013115).

| Exp. | Topic | Technique | File |
|------|-------|-----------|------|
| 1 | Insertion Sort and Selection Sort | Incremental | `insertion_selection_sort.c` |
| 2 | Binary Search | Divide and Conquer | `binary_search.c` |
| 3 | Quick Sort | Divide and Conquer | `quick_sort.c` |
| 4 | Fractional Knapsack | Greedy | `fractional_knapsack.c` |
| 5 | Prim's Algorithm (MST) | Greedy | `prims_algorithm.c` |
| 6 | Floyd-Warshall (All-Pairs Shortest Path) | Dynamic Programming | `floyd_warshall.c` |
| 7 | Sum of Subset | Backtracking | `sum_of_subset.c` |
| 8 | N-Queens | Backtracking | `n_queens.c` |
| 9 | Rabin-Karp String Matching | Hashing | `rabin_karp.c` |
| 10 | Min-Max | Divide and Conquer | `min_max_divide_conquer.c` |

## How to compile and run

```bash
gcc quick_sort.c -o quick_sort
./quick_sort
```

Works with any C compiler (gcc / clang / MinGW).
