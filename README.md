## 🚀 How to Run

### C Programs
Compile using GCC:
```bash
gcc filename.c -o output
./output
```

### 8086 Assembly Programs
Run using **emu8086** or **MASM/TASM**:
1. Open the `.asm` file in `emu8086`.
2. Click **Emulate** and step through execution or view memory/variables window.
